# Changelog

## 1.0.0 — 24 November 2026

Initial public release of the StudyStash Moodle plugin (`local_studystash`).

- Pair a Moodle site with StudyStash using an installation ID and one-time secret.
- Enable content access through connected LTI deployments or Moodle OAuth authorisation.
- Browse accessible courses and import visible files from File and Folder activities.
- Issue user-scoped tokens and temporary file-scoped import grants.
- Include file modification timestamps in import metadata for StudyStash previews.
- Provide Moodle audit events, Privacy API support and scheduled credential cleanup.
- Include automated plugin checks for Moodle 4.4 and 5.0.
